# Órbita — Atlas Coin

Site educativo estático em português, com dois ambientes, arte pixelada original, fonte local e Atlas Coin virtual.

## Publicar no GitHub Pages

Os arquivos index.html, styles.css, app.js, data.js, state.js e a pasta assets devem estar na raiz do repositório (não dentro de outra pasta orbita).

Em Settings → Pages, selecione Deploy from a branch, branch main, pasta /(root), e Save. Não há build ou dependências a instalar. O endereço esperado para thiagollipe-web/orbita será https://thiagollipe-web.github.io/orbita/ depois que a publicação terminar.

## Executar localmente

Execute `python3 -m http.server 4173` nesta pasta e abra http://localhost:4173.

## Escopo e dados

Seis lições de amostra, feedback, progresso e loja de insígnias. Cada missão única dá 20 Atlas Coin; a moeda não tem valor real. Dados ficam apenas no navegador. O progresso de localhost ou de outro domínio não migra automaticamente para github.io. Revisões não duplicam XP ou moedas. Nenhum dado de aluno está incluído neste pacote.

## Assets

Arte original do projeto. Pixelify Sans distribuída sob SIL OFL; licença em assets/OFL-PixelifySans.txt. Não há downloads de fontes ou chamadas de IA em runtime.
